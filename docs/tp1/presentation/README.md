# Presentación de TP1

[PowerPoint para exposición](veltis-keynote-tp1-exposicion.pptx)

La presentación distingue el producto completo (53 historias y 172 puntos) del
incremento de Sprint 1 (9 historias y 42 puntos). Relaciona propuesta de valor,
escenarios de calidad, decisiones ADD, pantallas, componentes y código real.

Las capturas nuevas se obtuvieron el 22 de octubre de 2026 desde la aplicación
local, en español, con viewport de 1920 × 1080 y datos académicos. Se conserva
el archivo completo de cada captura; las diapositivas amplían el contenido
relevante mediante recorte editable. La captura de reconocimiento muestra los
segundos restantes de la ventana de deshacer de 10 segundos.

Las notas del presentador incluyen explicaciones y referencias. El diagrama
general de dominio se conserva como una diapositiva de apoyo oculta; el C4 de
código visible muestra la ingesta de Monitoring y sus clases reales.

Las capturas no acreditan despliegue cloud, resultados comerciales ni estudios
de usabilidad. Los escenarios completos de carga y participantes requieren
validación independiente.
